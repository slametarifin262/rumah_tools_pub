## 🚀 Tentang RumahTools

**RumahTools** (`https://rumahtools.online`) adalah aplikasi web utilitas ringan dan cepat yang dirancang dengan pendekatan *Server-Side Rendering* (SSR). Platform ini menyediakan berbagai alat bantu digital praktis secara gratis yang dapat diakses langsung melalui peramban web tanpa perlu instalasi tambahan.

---

## 🛠️ Fitur & Modul Utama

1. **Pengolahan Dokumen & PDF:**
   * **PDF Merger:** Alat cepat untuk menggabungkan beberapa file PDF menjadi satu dokumen terpadu.
2. **Pengolahan Gambar & Geotagging:**
   * **Image Compressor:** Optimalisasi ukuran file gambar untuk efisiensi penyimpanan dan *bandwidth*.
   * **Geotagging Utility:** Menyisipkan metadata koordinat lokasi (*latitude* & *longitude*) dan stempel waktu ke dalam file gambar.
3. **Layanan Spasial / Geolocation:**
   * **Filter Kontak Darurat:** Layanan berbasis jarak untuk menyaring dan menampilkan daftar kontak darurat terdekat berdasarkan koordinat pengguna.
4. **Otomatisasi & Integrasi API:**
   * **Instagram Automated Posting:** Modul skrip yang terintegrasi dengan Instagram Graph API untuk publikasi konten otomatis.

---

## ⚙️ Stack Teknologi

* **Backend:** Node.js, Express.js
* **Frontend / UI:** EJS (Embedded JavaScript), HTML5, CSS3, JavaScript
* **Database:** MySQL
* **Infrastruktur / Deployment:** cPanel (Rumahweb), Node.js App Runner, Git, SSH / FTP
